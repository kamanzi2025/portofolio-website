AgriSmart

Web and mobile app
Live app Code

Helps smallholder bean farmers in East Africa decide when to plant, how much to water and how to deal with pests, using live weather for their location.

  • Planting advice built on Rwanda's two bean seasons and real agronomic thresholds, checked against a 5-day forecast.
  • Daily watering plan by growth stage, compared against expected rainfall.
  • Searchable library of common bean pests and diseases, with treatment and prevention steps.
  • Income and expense tracker that works offline.
  • React
  • TypeScript
  • Node.js
  • Express
  • Prisma
  • Expo
  • JWT auth
  • Vercel
  • Render

CaféCampus

Web platform
Live app Code

A food-ordering platform for a school campus. Students order from several restaurants, and each restaurant runs its own menu, orders and promotions.

  • Students can order as a guest, with an account, or with their student ID, and earn loyalty points.
  • Restaurants sign themselves up and go live straight away, with sales analytics on their dashboard.
  • Orders and menu changes update live for everyone through WebSockets.
  • A super-admin panel to approve, suspend or remove restaurants.

  • Tailwind
  • Zustand
  • Node.js
  • Express
  • Prisma
  • Socket.io
  • GitHub Actions

AutoParts Store Manager

Client project
Code

Business software built for an auto parts shop to run sales, stock and accounting in one place. It installs like an app and keeps working when the internet drops.

  • Sales, quotations, returns, purchases, suppliers, payments and stock transfers.
  • Full financial reports: profit and loss, balance sheet, cash flow, and money owed in and out.
  • Data saves on the device first and syncs to the cloud when the connection comes back.

  • PWA
  • IndexedDB (Dexie)
  • Supabase
  • Tailwind
